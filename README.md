# Receitas Fáceis

Receitas simples e saborosas para todos os dias

Live site: https://receitasfaceis.github.io/

A free, static recipe site in pt-BR. Pure HTML, CSS and vanilla JavaScript — no frameworks, no external libraries, no webfonts. All tools run entirely in the browser.

## Tools (on the home page)

- Ajustador de receitas
- Conversor de unidades
- Estimador de calorias por porção
- Substituições de ingredientes
- Planejador de refeições e lista de compras
